## §2 무엇을 고치나

```
행 만들기     load_pairs(..., include_no_condition=True) 가 조건없음 상품도 행으로 낸다 — pair_id 없음 · no_condition=True · 쌍(호출)은 만들지 않는다 (LLM 비용 0)
채점         score_all 이 no_condition 행을 items=[] · cap=None 으로 evaluate 한다 — **계산기는 안 바꾼다.** 기존 규칙대로 폭 0 이면 확정, 폭이 남으면(기본≠최고인데 조건이 없다) 계산불가
화면 경로만   웹 app.load · CLI ask_loop · 화면 계약 검사 · API 일치 검사 → include_no_condition=True
측정 경로는 그대로  ask_budget.curve(게이트) · measure_per_institution · scope_survey · prefs_survey · measure_r2 · score_extraction → 기본값 False. **게이트 64.3% 와 추출 지표의 분모는 안 바뀐다**(측정 뒤 정의 변경 금지)
질문         조건이 없으니 질문 0 개를 더한다 — question_plan 이 pair 없는 행을 건너뛴다
```
