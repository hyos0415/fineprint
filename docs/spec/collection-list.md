## 왜 이 목록인가

공시된 우대조건을 다 더해도 광고 최고금리에 안 닿는 상품이다.
**설명서에 나머지가 적혀 있는지 확인하면, 수집을 더 할지 말지가 정해진다.**

```
은행권 조건 있는 상품     81
  계산이 안 되는 상품     20
    설명이 모자란 것      14   ← 설명서를 보면 풀릴 수 있다. 이것부터
    우리가 더 뽑은 것     6   ← 파서 문제. 설명서로는 안 풀린다. 후순위
```

## 주의

- **자동 수집을 전제하지 않는다.** 직접 받는 것을 기본으로 한다
- 은행연합회(`portal.kfb.or.kr` · `www.kfb.or.kr`)는 `robots.txt`가 전체 차단이다. 대상에서 뺀다
- 일부 은행 사이트는 해외 IP를 막는다(제주은행 상품몰 확인). **국내에서 받아야 한다**
- 받은 원본은 커밋하지 않는다. `data/` 는 `.gitignore` 다
