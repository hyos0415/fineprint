# 상품설명서 수집 목록 — 계산이 안 되는 상품

> 작성 2026-08-26 · 스냅샷 `20260826` (은행권) 기준
> 근거: `design.md` §2 · 설계는 `problem.md` §5

## 확인 결과 (2026-08-26) — 1순위 근거가 사라졌다

**제주은행 J정기예금 설명서를 실물로 확인했다. 설명 안 되는 금리가 없었다.**
법정 공시 서류에서도 "이벤트시 비대면 채널에 고시한 우대금리를 추가 적용" 으로 끝낸다.
기본금리는 설명서와 공시가 여섯 구간 전부 일치했다.

기록: [`../decisions/0011-disclosure-docs-do-not-explain-the-gap.md`](../decisions/0011-disclosure-docs-do-not-explain-the-gap.md)

**그래서 이 목록의 목적이 바뀐다.** "설명 안 되는 금리를 찾는다"가 아니라
**"유형별로 한 번씩 확인한다"** 가 된다. 아래 1순위에서 성격이 다른 것만 골라 받으면 된다.

| 확인 | 상품 | 결과 |
|---|---|---|
| ✅ | 제주은행 J정기예금 `101272000057` | **없음** — "이벤트시 별도 고시" |
| ⬜ | 케이뱅크 궁금한 적금 `01012000200000000004` | 유형이 다르다 — "입금할 때마다 랜덤" |
| ⬜ | 케이뱅크 마이키즈 적금 `01012000200000000006` | 유형이 다르다 — "금리쿠폰 입력시" |

**설명서에만 있는 것은 따로 있다** — 세제 혜택(비과세종합저축 가능 여부)·가입 제한·
중도해지 이자율·만기후 이자율. API 에는 하나도 없다. 수집은 그 목적으로 계속한다.

## 왜 이 목록인가

공시된 우대조건을 다 더해도 광고 최고금리에 안 닿는 상품이다.
**설명서에 나머지가 적혀 있는지 확인하면, 수집을 더 할지 말지가 정해진다.**

```
은행권 조건 있는 상품     81
  계산이 안 되는 상품     20
    설명이 모자란 것      14   ← 설명서를 보면 풀릴 수 있다. 이것부터
    우리가 더 뽑은 것     6   ← 파서 문제. 설명서로는 안 풀린다. 후순위
```

## 1순위 후보가 하나 생겼다 — `0011`의 반증 기회 (2026-08-27 · `decisions/0019`)

`0011`은 *"설명 안 되는 금리가 설명서에도 없었다"*고 결론냈는데 **표본이 제주은행
J정기예금 하나**였다. 표본 검토(`prereg-06` §1.8)에서 **성격이 다른 사례**가 나왔다.

| 은행 | 상품 | 구분 | 무엇을 확인하나 |
|---|---|---|---|
| 국민은행 | **KB 특★한 적금** | 적금 | 조건문 ③번이 `"함께해요 우대이율: 최고 연 2.0%p"` 뿐이다. **무엇을 하라는지 안 적혀 있다.** 설명서에 있나 |
| 국민은행 | **KB내맘대로적금** | 적금 | 9개 항목 중 `"소중한 날"`의 뜻이 공시에 없다. 은행원도 설명 못 한 항목이라는 증언이 있다 |
| 부산은행 | **부산이라 좋다 Big적금** | 적금 | 조건문이 `"*우대이율 6개월 미만 최대2.00%, 6개월 이상 2.20%"` 한 줄이 전부다 |

**J정기예금과 다른 점** — 그때는 *"금리 폭이 설명되지 않는다"*였고, 이번은
**"금리는 맞는데 조건이 무엇인지 안 적혀 있다"**다. 후자는 설명서에 있을 가능성이
더 크다(설명서에는 우대조건 상세표가 따로 붙는 경우가 있다).

**무엇이 관측되면 `0011`이 틀린 것인가** — 위 셋 중 하나라도 설명서에 조건이 적혀
있으면, "설명서는 도움이 안 된다"는 결론이 **상품군을 가려서 다시 서야 한다.**
그러면 상품설명서가 다시 1순위로 올라간다.

- 받은 원본은 커밋하지 않는다. `data/` 는 `.gitignore` 다
