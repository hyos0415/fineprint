## 사람 확정 override (3건)

**NH1934월복리적금** → 층 `닫힘`

> '1. 급여실적 : 1.0%p (①/② 중복 적용 불가)'는 ①②의 상위 라벨이다. 그대로 두면 ①과 이중 계산된다. 상위 라벨을 빼면 항목 합이 1.0(급여 ①) + 0.3(비대면 이체) + 0.2(마케팅) + 2.0(농업계고) = 3.5 로 폭(+3.50)과 정확히 일치하므로 층은 닫힘이다.

**JB 123 정기예금 (만기일시지급식)** → 층 `닫힘`

> 회차별 자동재예치 우대(1/2/3회차)는 서로 배타이고 신규 가입에는 적용되지 않는다. 그 줄들을 빼면 이벤트 우대 0.50(정기예금 보유이력 없음) + 0.10(정보 동의) = 0.60 으로 폭(+0.60)과 일치한다.

**KB맑은하늘적금** → 층 `닫힘`

> '- 1년제 최고 연 0.8%p, 2년제 …'는 가입기간별 상한 표기인데 자동 규칙이 항목으로 셌다. 또 '③ 대중교통 미션: 1년제 연 0.4%p, 2년제 연 0.5%p'처럼 한 줄에 기간별 값이 여러 개면 규칙 D(최댓값)가 2년제 값을 골라 부풀렸다. 12개월 기준 항목은 0.1+0.2+0.4+0.1 = 0.8 로 폭(+0.80)과 일치한다. **정답 계산 시 ③은 0.4로 본다.**
