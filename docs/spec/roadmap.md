# 전체 과업 지도 — 파이프라인을 완성하려면 무엇이 남았나

> 작성 2026-08-31 · 현재 상태와 다음 할 일은 [`../../START-HERE.md`](../../START-HERE.md) ·
> 부품별 계약은 [`design.md`](./design.md) · 문제 정의는 [`problem.md`](./problem.md) ·
> **수집이 어떻게 도는지는 [`collection-pipeline.md`](./collection-pipeline.md)**

## 이 문서는 계약이 아니라 지도다

**항목이 적혀 있다는 것은 만들기로 했다는 뜻이 아니다.** 선행 조건이 채워지고
`design.md` 의 *"없으면 어떻게 되나"* · *"무엇으로 값어치를 재나"* 가 적힌 뒤에 만든다
(`CLAUDE.md` 1번). 이 프로젝트는 실제로 방향을 여러 번 뒤집었다 — `0009`(검증기 →
추천기) · `0026`(완주율 폐기) · `0027`(수치 질문 폐기) · `0028`(후보 집합 도입).
**대기 항목은 실험 결과에 따라 바뀐다.**

그래서 규칙이 하나 붙는다.

```
이슈로 만든다      착수 가능한 것 (▶) 과 진행 중인 것
문서에만 둔다      선행 조건 대기 (⏸) — 조건이 풀리는 순간 이슈를 판다
```

**이 문서가 상태의 원본이다.** 에픽 이슈(#16~#20)에는 내용을 적지 않고 이 문서를
가리킨다 — 원본이 두 군데면 서로 다른 말을 하기 시작한다.

기호: `✅` 완료 · `▶` 지금 가능 · `⏸` 선행 조건 대기 · `🙋` 사람이 정할 것

## 지도가 말하는 것 — 구멍은 RAG 가 아니다

```
problem.md 가 약속한 것   "내 상황(사실) + 내 선호(가중치) 로 골라준다"
지금 만든 것             내 상황 → 실수령 금리 범위
                       선호 → 가중치 → 정렬                ← 2026-08-31 에 채웠다 (`0030`)
안 만든 것               리포트 → UI                       ← 화면이 아직 CLI 뿐이다
```

**크리티컬 패스는 `D7 → E6 → E5 → F1 → F4` 였고, 2026-08-31 에 앞 넷이 닫혔다**
(`0030` 이슈 #24 · `0036` 이슈 #33). 남은 것은 **F4(UI)** 하나이고 **계획까지 세웠다** —
[`ui-plan.md`](./ui-plan.md). 첫 작업은 화면이 아니라 **F4-0(계약을 객체로)** 다. 반대로 G(검색·리랭커)는
전부 코퍼스 대기라 지금 손댈 수 없고, `CLAUDE.md` 1번이 막는 방향이 정확히 그쪽이다.

**시간이 정하는 것 셋.**

```
                    assert 도 없다** — 옮길 때 조용히 사라질 수 있다 (`0034` D3)

```
