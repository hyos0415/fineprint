# 전체 과업 지도 — 파이프라인을 완성하려면 무엇이 남았나

> 작성 2026-08-31 · 현재 상태와 다음 할 일은 [`../../START-HERE.md`](../../START-HERE.md) ·
> 부품별 계약은 [`design.md`](./design.md) · 문제 정의는 [`problem.md`](./problem.md) ·
> **수집이 어떻게 도는지는 [`collection-pipeline.md`](./collection-pipeline.md)**

## 이 문서는 계약이 아니라 지도다

**항목이 적혀 있다는 것은 만들기로 했다는 뜻이 아니다.** 선행 조건이 채워지고
`design.md` 의 *"없으면 어떻게 되나"* · *"무엇으로 값어치를 재나"* 가 적힌 뒤에 만든다
(`CLAUDE.md` 1번). 이 프로젝트는 실제로 방향을 여러 번 뒤집었다 — `0009`(검증기 →
추천기) · `0026`(완주율 폐기) · `0027`(수치 질문 폐기) · `0028`(후보 집합 도입).
**대기 항목은 실험 결과에 따라 바뀐다.**

그래서 규칙이 하나 붙는다.

```
이슈로 만든다      착수 가능한 것 (▶) 과 진행 중인 것
문서에만 둔다      선행 조건 대기 (⏸) — 조건이 풀리는 순간 이슈를 판다
```

**이 문서가 상태의 원본이다.** 에픽 이슈(#16~#20)에는 내용을 적지 않고 이 문서를
가리킨다 — 원본이 두 군데면 서로 다른 말을 하기 시작한다.

기호: `✅` 완료 · `▶` 지금 가능 · `⏸` 선행 조건 대기 · `🙋` 사람이 정할 것

## G. 검색과 리랭커 · 에픽 [#20](https://github.com/hyos0415/fineprint/issues/20)

**첫 근거 있는 수요가 생겼다** (2026-09-02 · `prereg-14` §7). 지금까지 이 문서는
*"구멍은 RAG 가 아니다"* 라고 적어 왔는데, 사람 완주에서 **공시 안에 답이 없는
낱말**이 나왔다.

```
탑스      제주은행 · 제주Dream 정기예금    "③탑스, 주거래 고객"
소중한 날   국민은행 · KB내맘대로적금       "… 장기거래, 첫 거래, 주택청약종합저축, 소중한 날"
```

둘 다 `spcl_cnd`(우대조건) 칸에만 나오고 `etc_note`·`join_member`·`join_deny`·
`mtrt_int` **어디에도 정의가 없다**. 사람이 답을 고를 수 없었다(M1b 2건).
표본 1명이라 이것은 수요의 **존재** 증거이지 크기 증거가 아니다.

**선행이 A2 가 아니다** (2026-09-02 정정 — 같은 날 앞서 "선행은 그대로 A2" 라고
적었는데 틀렸다). 사람이 **국민은행 적금 상품설명서를 직접 뜯어 봤고 "소중한 날"
설명이 없었다.** 다른 사례도 설명서가 디테일을 해결해 주지 않았다.

```
공시 (baseList)      spcl_cnd 에 낱말만 있고 뜻이 없다        확인함
상품설명서 (A2)       거기에도 없다                        **사람이 직접 확인함**
그럼 어디에 있나       은행 서비스 소개 페이지 · 이벤트 공지 · 앱 화면?   **모른다**
```

그래서 **G 의 선행이 "코퍼스를 A2 에서 얻는다" 에서 "코퍼스를 어디서 얻나부터
조사한다" 로 바뀐다.** 이것은 `0011` 이 이미 겪은 것과 같은 모양이다 — *"법정 공시
서류에서도 이벤트시 별도 고시로 끝난다"*. 그때는 금리였고 이번엔 용어다.

**우리가 용어 사전을 만드는 쪽은 여전히 안 간다**(`0019` 위험 — 뜻을 모르는 낱말의
뜻을 우리가 지어낼 수 없다). 다만 **우리가 만든 내부 용어**는 다른 문제다 —
그건 우리가 뜻을 알므로 사전을 써도 지어내는 것이 아니다(아래 F5).

**조사했다 (2026-09-04 · `prereg-26` · 이슈 [#71](https://github.com/hyos0415/fineprint/issues/71) · 1차).**

**코퍼스는 상품설명서(A2)가 아니라 기관 상품 상세 페이지(A2')다.** 그런데 **모양이 기관마다 다르다**(정적 HTML ·
JS 렌더 · 접속 거부 · PDF 특약 · 그룹사 페이지) — 단일 크롤 규칙이 없고 헤드리스 브라우저 없이는 반을 못 읽는다.
그리고 **다 있지도 않다**(올해의 띠). 찾은 뜻은 판정에 넣지 않았다(`0019`).

**사람이 정했다 (`0056` · 같은 날)** — **코퍼스는 지금 모으지 않는다.** 도구가 못 읽은 4건을 사람이 찾지 않고, 뜻 없는
낱말은 `0050` 그대로 "은행 확인이 필요한 조건" 이다(이제 옆에 F3 의 링크·전화가 있다). G 의 착수 조건은 **뜻 없는
낱말로 답을 못 고른 사람 세션이 쌓일 때**(지금 2건 · 1명)이고, 그때 수집 범위와 판정 근거 여부를 정한다. #71 닫힘.

## 지도가 말하는 것 — 구멍은 RAG 가 아니다

```
problem.md 가 약속한 것   "내 상황(사실) + 내 선호(가중치) 로 골라준다"
지금 만든 것             내 상황 → 실수령 금리 범위
                       선호 → 가중치 → 정렬                ← 2026-08-31 에 채웠다 (`0030`)
안 만든 것               리포트 → UI                       ← 화면이 아직 CLI 뿐이다
```

**크리티컬 패스는 `D7 → E6 → E5 → F1 → F4` 였고, 2026-08-31 에 앞 넷이 닫혔다**
(`0030` 이슈 #24 · `0036` 이슈 #33). 남은 것은 **F4(UI)** 하나이고 **계획까지 세웠다** —
[`ui-plan.md`](./ui-plan.md). 첫 작업은 화면이 아니라 **F4-0(계약을 객체로)** 다. 반대로 G(검색·리랭커)는
전부 코퍼스 대기라 지금 손댈 수 없고, `CLAUDE.md` 1번이 막는 방향이 정확히 그쪽이다.
