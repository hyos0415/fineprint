# prereg-20 · 기관 정보 수집(A7) — 홈페이지 URL · 대표전화가 어디까지 채워지는가

> 작성 2026-09-04 (**수집 전**) · 이슈 [#58](https://github.com/hyos0415/fineprint/issues/58) ·
> 근거 `0037`(링크만 주고 가입은 받지 않는다 · 로드맵 F3 의 데이터가 없다는 발견) · 로드맵 §A A7

## §1 없으면 어떻게 되나

F3(홈페이지 링크 · 대표전화)을 만들 재료가 없다. 상품 공시(`baseList`)에 두 필드가 없고
(`0037` — `data/raw` 전체에서 `homp_url` 이 있는 파일 0개), 금융감독원 API 의 **금융회사 조회**
엔드포인트(`companySearch.json`)에 있다. 사유 문장 셋(`조건불명`·`뜻없음`·`추첨`)이 전부
*"은행에 확인해 보세요"* 로 끝나는데 갈 곳이 화면에 없다.

## §2 무엇을 만드나

- `src/ingest/fetch_companies.py` — 두 권역(은행 `020000` · 저축은행 `030300`)을 전 페이지 받아
  `data/raw/company_{권역}_{YYYYMMDD}.json` 으로 저장한다. **원본은 커밋하지 않는다**(`.gitignore`).
  키 로딩·페이지 순회·User-Agent 는 `fetch_finlife.py` 를 그대로 따른다
- `--check` — 최신 상품 스냅샷의 기관 코드(`fin_co_no`)와 짝지어 **집계만** 낸다. 문서에 적는 것은
  집계 결과다
- **하지 않는 것** — 없는 기관을 웹 검색으로 채우지 않는다(추측 금지 · `0016`). URL 에 추적
  파라미터를 붙이지 않는다(`0037`). 이 이슈는 수집까지이고 화면(F3)은 다음 이슈다

## §3 예측 — 받기 전에 적는다

상품 스냅샷(은행 20260826 · 저축은행 20260825)에 나오는 기관은 **은행권 18곳 · 저축은행 79곳**이다.

```
P1  짝        상품의 기관 코드 97개가 회사 목록에 전부 있다 (빠진 기관 0)
P2  홈페이지   짝지어진 기관의 homp_url 이 비어 있지 않은 비율 — 은행권 100% · 저축은행 ≥ 95%
P3  전화       cal_tel 이 비어 있지 않은 비율 — 두 권역 ≥ 90%
P4  이름       같은 코드의 kor_co_nm 이 상품 목록과 글자까지 같다 (불일치 0)
P5  링크 형태   homp_url 전부 http:// 또는 https:// 로 시작하고 ? 가 없다
```

## §4 판정 조항

```
P1 이 틀리면   그 기관은 F3 에서 "링크 없음" 으로 정직하게 비운다. 다른 곳에서 채우지 않는다
P2·P3 이 틀리면  F3 는 있는 것만 보이고 없는 칸을 비운다. 얼마나 비는지가 F3 화면 설계의 입력이다
P4 가 틀리면   화면 표기는 상품 쪽 이름을 쓰고 회사 목록은 코드로만 짝짓는다. 불일치 목록을 §5 에 적는다
P5 가 틀리면   파라미터를 우리가 떼지 않고 API 값 그대로 둔다 (우리가 붙인 것이 아니다) · `0037` 에 기록
```
