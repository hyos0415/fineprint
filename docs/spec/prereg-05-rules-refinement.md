# 사전 등록 05 — 규칙 파서 깎기 1라운드

> 등록일 2026-08-25 · 상태: **예측만 있음 (구현 전)** · 이슈 #6
>
> `prereg-03`이 끝나 홀드아웃 비교가 완료됐으므로 이슈 #6을 연다. 이 문서는 규칙을
> 고치기 **전에** 무엇을 고칠지·얼마나 오를 것인지·언제 멈출지를 고정한다.

## 0. 답하는 질문

> **규칙 파서가 닫지 못하는 94행의 실제 원인은 무엇이고, 그중 규칙으로 고칠 수 있는
> 것을 고치면 얼마나 오르는가?**

## 1. 어디서 깎는가 — 개발 집합만 쓴다

```
개발 집합   은행권 253행      ← 여기서만 규칙을 고친다
홀드아웃    저축은행 182행     ← 보지 않는다. 다 끝난 뒤 한 번만 재고 반복하지 않는다
```

`prereg-03`이 저축은행에서 A를 62.6%로 측정했다. **그 182행을 보고 규칙을 고치면
`prereg-04`가 쓸 홀드아웃이 없어진다.** 규칙을 깎는 것은 개발 집합에서만 하고,
홀드아웃은 **끝난 뒤 일반화 확인용으로 한 번만** 재고 그 결과로 규칙을 다시 고치지 않는다.

## 1.1 먼저 채점 정의를 고친다 (규칙을 고치기 전)

**항목 0개 34행 중 14행은 실제 금리폭이 0이다.** 공시가 "우대분 없음"이라고 말하는
행이고, 파서가 아무것도 뽑지 않은 것은 **옳은 행동**이다. 그런데 구현이 "항목이 0개면
닫히지 않음"으로 세고 있었다.

`prereg-03` §3의 정의를 **글자대로** 읽으면 합계 0 == 폭 0이므로 **닫힘**이다.
정의에 없던 `항목 수 > 0` 조건이 코드에만 있었다. **정의를 정본으로 삼는다.**

```
                        구현 수정 전   정의대로
  개발 A (은행권 253행)     62.8%    →   68.4%   (173/253)
  홀드아웃 A (1,090행)      10.5%    →   30.1%
  홀드아웃 B (1,090행)      13.6%    →   32.7%
```

**`prereg-03`의 판정은 바뀌지 않는다.** 30.1%·32.7%도 둘 다 40% 미만이라 §8 두 번째
반증 조건이 그대로 발동하고, 폭 > 0인 182행에서는 A 62.6% / B 71.4%가 그대로다
(그 부분집합에는 "항목 0개 + 폭 0" 행이 없다). §7의 결론은 손대지 않는다.

**이 5.6%p는 규칙이 번 것이 아니다.** 그래서 아래 라운드 예측은 **68.4%를 기준선으로**
잡는다. 정의가 번 몫과 규칙이 번 몫을 섞지 않는다.

## 2. 진단 — 이슈 #6이 추정한 원인은 틀렸다

이슈 #6은 가장 큰 덩어리(0.30~1.00 · 22행)의 원인을 **"배타 그룹 미처리 — 중복 적용
불가"**로 추정했다. 실측하니 아니다.

```
닫히지 않은 행 중 "중복 적용 불가"가 명시된 행    3
"중복 적용 불가"가 명시된 행 전체               11   (대부분은 이미 닫힌다)
```

닫히지 않은 행을 실제로 읽어 원인을 넷으로 갈랐다.

| 원인 | 무엇인가 | 예 |
|---|---|---|
| **(1) 항목별 상한을 문서 상한으로 오인** | 항목 줄에 붙은 `최고 0.5%p`를 문서 전체 상한으로 잡거나, 그 항목의 하위 값들을 합해 버린다 | NH올원e 미니적금 · 카카오뱅크 한달적금 · IBK탄소제로적금 · KB 특★한 적금 |
| **(2) 대안 묶음을 합산** | 회차별·일수별·고객유형별 나열은 **하나만 받는다**. 지금은 다 더한다 | JB 123(1·2·3회차) · 토스뱅크 키워봐요(3·7·14·21·31일) · 오면우대(신규/기존 고객) |
| **(3) 기간별 상한·항목 처리** | 기간마다 상한이 다른데 하나로 잡거나, `1년제 최고 0.8%p`를 항목으로 센다 | KB맑은하늘적금 · The든든예금 · 더(The) 특판 정기예금 |
| **(4) 진짜 설명 불가** | 공시가 수치 없는 우대를 언급한다 — `"이벤트시 디지털 채널에 고시한 우대금리를 추가 적용할 수 있음"` | J정기예금 · 스마일드림 정기예금 · 신한My플러스 |

**(1)과 (2)는 같은 뿌리다** — 어떤 항목 묶음은 **합이 아니라 최댓값**이다.
**(4)는 규칙으로 고칠 수 없다** — 이 행들은 닫히지 않는 것이 맞다.

### 2.1 원인별 규모 (정의 수정 후 기준선 68.4% · 닫히지 않은 80행)

| 원인 | 행 | 상품 | 순수 대상 |
|---|---:|---:|---|
| (1) 항목별 상한 — **규칙 H** | 29 | 11 | (1)+(2) 합쳐 **34행 = 13.4%p** |
| (2) 대안 묶음 — **규칙 I** | 7 | 5 | 〃 |
| (3) 기간 표기 — **규칙 J** | 14 | 6 | **13행 = 5.1%p** |
| (0) 조건문에 % 숫자가 없음 | 3 | 1 | **못 고친다** (합쳐 13행 = 5.1%p) |
| (4) 수치 없는 우대 언급 | 10 | 3 | 〃 |
| (5) 분류 안 됨 | 19 | 7 | 모른다 — 정직하게 적어 둔다 |

"순수 대상"은 다른 원인에 걸리지 않고 그 규칙만 필요한 행이다. 한 행이 여러 원인에
걸릴 수 있으므로 열의 합은 80을 넘는다.

**천장은 94.9%다** — 못 고치는 13행을 빼면 그 이상은 올라갈 수 없다.

**(3)을 이번에 포함한다. 단 라운드를 가른다.** 세 규칙을 한 번에 넣으면 결과가 중간쯤
나올 때 어느 규칙이 기여했는지 가릴 수 없다. 이 프로젝트가 쓰는 ablation의 반대다.

## 3. 넣을 규칙 — 라운드 1은 H·I, 라운드 2는 J

**규칙 H — 중첩 상한.** 항목 줄에 `최고/최대 N%p`가 있고 그 **뒤에 하위 값이 나열되면**,
그 묶음의 기여값은 **N**이고 하위 값은 더하지 않는다. 문서 전체 상한과 구분한다.

```
"1. 자동이체 입금횟수 우대금리 : 최고 0.5%p - 5회이상 0.2%p, 10회이상 0.3%p, 15회이상 0.5%p"
   지금  →  항목 0.5·0.5·0.5·0.2 를 더한 뒤 문서 상한 0.5 로 자름
   고침  →  이 묶음의 기여값은 0.5 하나
```

**규칙 I — 대안 묶음.** 같은 축(회차·일수·인원·고객유형)으로 값이 나열되면 합이 아니라
**최댓값**이다.

```
"3일 저금 성공 시 2.0% / 7일 3.0% / 14일 5.0% / 21일 7.0% / 31일 9.0%"
   지금  →  2.0 + 3.0 = 5.0        고침  →  9.0
```

**규칙 J — 기간별 상한·기간 라벨** (라운드 2). `1년제 최고 연 0.8%p`처럼 기간이 붙은
상한은 **그 기간의 문서 상한**이고 항목이 아니다. `다. 12개월 특판 우대이율 : 0.55%`처럼
기간 라벨이 숫자 앞에 오지 않는 형태도 기간 표기로 인식한다.

```
"- 1년제 최고 연 0.8%p, 2년제 최고 연 0.9%p, 3년제 최고 연 1.0%p ① 종이통장 0.1%p …"
   지금  →  0.8 을 항목으로 세고 상한은 없다고 본다
   고침  →  12개월이면 상한 0.8, 항목은 ①~④ 만
```

## 4. 예측과 임계 (구현 전에 고정)

기준선: **닫힘률 68.4%(173/253) · 항목 0개 13.4%(34/253)** — §1.1의 정의 수정 후 값이다.

| 라운드 | 넣는 것 | 예측 | 멈추는 선 |
|---|---|---|---|
| **1** | 규칙 H + I | **74% 이상** (187/253 이상) | **71% 미만이면 멈춘다** |
| **2** | 규칙 J | 라운드 1 결과 **+3%p 이상** | +1%p 미만이면 J를 되돌린다 |

**공통 임계 (두 라운드 모두)**

| | 기준 |
|---|---|
| 회피 방지 | **항목 0개 비율이 13.4%를 넘지 않는다.** 넘으면 실패 — 뽑기를 포기해 얻은 점수다 |
| 부 지표 | **못 고치는 13행은 계속 닫히지 않는다.** 닫히면 규칙이 원인을 고친 게 아니라 숫자를 맞춘 것이다 |
| 천장 | 94.9% (못 고치는 13행 제외) |

**74%를 잡은 근거**: H·I 순수 대상이 34행 = 13.4%p다. 그 전부를 잡으면 81.8%가 되지만,
(5) 분류 안 됨 19행에 섞인 것과 여러 원인에 동시 걸린 행이 있어 절반 정도를 기대한다 —
68.4% + 6%p ≈ 74%. **71% 미만이면** 순수 대상의 5분의 1도 못 잡은 것이므로 방향을 접는다.

**J의 +3%p 근거**: 순수 대상 13행 = 5.1%p. 그 절반 이상을 기대한다.

## 5. 반증 조건

- **라운드 1이 71% 미만이면** → 규칙으로 표기 변형을 흡수하는 방향이 한계에 왔다는
  `0004`의 판단이 맞은 것이다. 이슈 #6을 닫고 `prereg-04`로 간다
- **라운드 2가 +1%p 미만이면** → 기간 표기는 규칙으로 다룰 문제가 아니다. J를 되돌린다
- **항목 0개 비율이 오르면** → 규칙 H가 항목을 지우고 있다. 되돌린다
- **홀드아웃(저축은행 182행)에서 62.6%보다 떨어지면** → 개발 집합에 과적합한 것이다.
  **그 경우에도 규칙을 다시 고치지 않는다** — 사실만 기록하고 `prereg-04`에 넘긴다
- **(4) 진짜 설명 불가 행이 닫히면** → 규칙이 원인을 고친 게 아니라 숫자를 맞춘 것이다
