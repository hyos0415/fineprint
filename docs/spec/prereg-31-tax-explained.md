# prereg-31 · 리포트 끝에 "세금은 이렇게 계산했습니다" — 세율 · 뗀 금액 · 조문을 설정 파일에서 읽어 보인다

> 작성 2026-09-09 (**고치기 전**) · 이슈 [#80](https://github.com/hyos0415/fineprint/issues/80) · 근거 `config/tax-2026.json`(`0032` · 조문 좌표 · 법제처 대조) ·
> `design.md` §세금 계산(3층 · 최종 세액은 내지 않는다) · 앞선 `prereg-25`(A18) · `prereg-30`(월 환산)
> 사람 요청 — *"세금 계산이 어떻게 이루어졌는지 마지막에 한번 얘기해주면"* · 사람 결정 — **리포트에만 · 맨 끝**

## §1 무엇이 빠져 있나

리포트는 "세금 15.4% 를 떼면 = 세후" 까지 말한다. **15.4% 가 어디서 왔는지**(어느 법 어느 조문)와 **실제로 뗀 금액이 몇 원인지**는 말하지 않는다.
사용자는 숫자를 받아들이거나 스스로 찾아야 한다. 근거는 이미 저장소에 있다 — `config/tax-2026.json` 이 세율마다 조문을 달고 있고 2026-08-31 에
법제처 원문과 대조했다(`0032`). 즉 새로 알아낼 것은 없고 **있는 것을 문장으로 풀어 보이는 일**이다.

## §2 무엇을 만드나

리포트 텍스트와 웹 리포트 카드의 **맨 끝**에 한 덩이. 문장의 재료는 `calculate.tax_explained(s, 이자, tax)` 한 곳이 만들고 텍스트·웹은 그것을 꽂는다.

```
세금은 이렇게 계산했습니다
  세전 이자 1,825,000원 × 15.4% = 세금 281,050원 → 세후 1,543,950원         ← 가입 금액이 있을 때만 · 범위면 범위로
  15.4% = 이자소득세 14% (소득세법 제129조제1항제1호라목) + 지방소득세 1.4% (지방세법 제103조의13제1항 · 소득세의 10%)
  비과세종합저축 대상(만 65세 이상 · 장애인 등)이면 0% — 조세특례제한법 제88조의2 · 원금 5천만원 · 2028-12-31 가입분까지
  연 이자·배당 합계 2,000만원(소득세법 제14조제3항제6호)을 넘으면 초과분은 종합과세 — 이 화면은 넘는지만 말하고 세액은 계산하지 않습니다
```

지키는 것

- **숫자와 조문은 전부 `tax-2026.json` 에서 읽는다.** 14 · 1.4 · 15.4 · 5천만원 · 2,000만원 · 조문 번호를 코드에 다시 적지 않는다. 파일이 바뀌면 문장이 따라 바뀐다
- **세금 원 = 세전 − 세후** (계산기가 이미 낸 두 값의 차). 새 곱셈으로 다른 값을 만들지 않는다 — 반올림 때문에 세전×세율과 1원 다를 수 있고, 그때 맞는 것은 세전−세후다
- 비과세(세율 0)인 상품은 첫 줄이 *"비과세종합저축 대상으로 답해 세금 0원"* 이 된다. 일반과세 줄은 그대로 보인다(왜 0 인지 대비가 되게)
- **최종 세액은 내지 않는다.** 종합과세 층은 기준선과 조문만
- A18 확장 — 리포트에 세율(%)이 보이면 **그 근거 조문 문자열**이 같은 리포트 안에 있어야 한다(텍스트·웹). 조문 문자열은 설정 파일의 것과 글자가 같아야 한다

## §3 예측

```
P1  무변동    금리 · 순서 · tier · caveats · 세전·세후 총액 · 종합과세 판정이 고치기 전과 같다 (은행권 12개월 79상품 · 두 금액)
P2  일치      "세금 ○원" = 세전 − 세후 가 두 권역 모든 상품에서 성립 (lo·hi 각각)
P3  A18      텍스트·웹 리포트에 조문 문자열 셋(소득세법 제129조 · 지방세법 제103조의13 · 소득세법 제14조)이 설정 파일 글자 그대로 있다. 두 권역 · hi/lo 통과.
             음성 — 설정 파일의 조문 문자열을 바꾸면 화면도 같이 바뀐다(코드에 사본이 없다)
P4  금액 없음  가입 금액이 없으면 첫 줄(원 금액)만 빠지고 나머지 세 줄은 있다
P5  길이     리포트 하나가 4줄 늘어난다 — 텍스트 리포트 5개 기준 20줄. 화면 아래쪽이라 목록 읽기를 방해하지 않는다 (판단 · 근거 없음)
```

## §4 판정 조항

```
P1 이 틀리면   계산기를 건드린 것 — 되돌린다. 이 작업은 표시만이다
P2 가 틀리면   세금 원을 따로 곱한 것 — 세전−세후로 고친다
P3 이 틀리면   조문이 코드에 사본으로 있거나 렌더러가 빠뜨린 것 — 사본을 지우고 설정 파일에서 읽게 한다
```
