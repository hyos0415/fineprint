# 0054 · 이어하기 코드는 사용자가 든다 — 서버는 여전히 아무것도 저장하지 않는다

2026-09-04 · 이슈 [#67](https://github.com/hyos0415/fineprint/issues/67) · `prereg-24` ·
앞선 결정 `0026` D3(피로는 이어하기·순서·문구로 다룬다) · `0040`(무상태 · 이어하기는 클라이언트 보관으로 공짜) ·
`0043`(서버가 정하고 템플릿은 꽂는다)

## Decision

```
D1  웹 — 화면 아래 **이어하기 코드**(스냅샷·권역·기간·스코프·선호·정렬·답 전부를 담은 JSON 한 줄)를 텍스트 상자로
    보인다. 0단계 폼의 같은 이름 칸에 붙여 넣으면 그 화면이 그대로 이어진다. 코드가 있으면 폼의 다른 칸은 덮인다
D2  CLI — `ask_loop.py --resume <세션 로그>`. 로그의 스냅샷·권역·기간·스코프·선호·`state`·첫 화면(`start`)을
    이어받아 다음 질문부터 묻는다. 세션 로그에 `company`·`kinds`·`prefs_arg`·`start`·`resumed_from` 을 더했다
D3  **서버는 저장하지 않는다.** 세션 · 쿠키 · 계정 · `localStorage` · 다운로드 링크 없음. 코드는 사용자가 들고,
    화면이 그렇게 말한다 — *"답은 서버에 남지 않습니다. 이어서 답하려면 아래 코드를 복사해 보관해 두세요"*
D4  코드는 서버가 만든다(`app.resume_code`). 템플릿은 꽂기만 한다. 잘못된 코드는 다른 입력 오류와 같은 경로로
    HTML 문장이 된다 (`0040` 의 에러 계약)
```

## Evidence

`prereg-24` §5 — 여섯 예측 전부 적중. 이어받은 화면은 원 화면과 **바이트 동일**(CLI 문자열 · 웹 HTML)이고,
가장 긴 경로의 코드가 4KB 로 `0040` 임계(10KB)의 40% 다. JS 없이 돈다.

**P1 이 한 번 틀린 것이 이 결정의 D2 를 정했다.** 처음엔 `state` 만 이어받았는데 성과 줄의 "폭 1.18 → 0.08%p"
가 사라졐다 — 폭 변화의 기준(첫 화면)이 세션 안에만 있었다. 이어하기는 **답을 이어받는 것이 아니라 여정을
이어받는 것**이라, 여정이 시작한 화면도 로그에 남긴다.

`0026` 이 *"세션 로그에 상태가 이미 다 들어 있으므로 재개는 어렵지 않다"* 고 적었는데 **스코프가 없었다.**
로그만 보고 "다 들어 있다" 고 한 것이 틀렸고, 실제로 넣어 보니 빠진 것이 넷이었다(스코프 둘 · 선호 원문 · 첫 화면).

## Alternative

- **A. 서버 세션(파일·SQLite)** — `0040` 이 기각한 것. 저장이 생기는 순간 `0026` 반증 조건(개인정보 최소수집)이
  발동하고, 재시작에 묶인다
- **B. `localStorage` 에 자동 저장** — JS 가 필요하고(`0038` 점진적 향상 위반은 아니지만) 기기에 답이 남는다.
  사용자가 모르는 채로 남는 것이 문제다 — 코드는 사용자가 **보고 복사한** 것만 남는다
- **C. 다운로드 링크(`.json` 파일)** — `0040` 반증 조건이 "잃으면 파일 내려받기부터" 로 **순서**를 적어 뒀다.
  텍스트 상자로 안 되는 것이 관측되면 그때 만든다. 지금은 근거 없는 편의다
- **D. URL 에 코드를 싣는다(GET)** — 답이 URL·서버 로그에 남는다. `0040` 이 PRG 를 안 쓴 이유와 같다
- **E. 코드를 짧게 압축·인코딩한다** — 4KB 를 줄일 이유가 없고, 사용자가 **읽을 수 있는** JSON 이 "무엇이
  저장되는가" 를 스스로 말한다

## Why rejected

위에 같이 적었다.

## 반증 조건

- **사람 세션에서 코드를 잃어 이어하기를 못 한 경우가 나오면** — 텍스트 상자 복사가 실제로는 안 되는 것이다.
  대안 C(파일 내려받기)를 만든다 (`0040` 이 정한 순서)
- **코드가 10KB 를 넘으면** — `0040` 반증 조건 1 과 같은 자리. 서버 세션(A)을 다시 본다
- **사용자가 코드를 붙여 넣고 "왜 위에서 고른 게 무시되나" 하면** — D1 의 덮기 규칙이 화면에서 안 읽힌 것이다.
  안내 문장의 위치·문구를 고친다
- **옛 로그를 스코프 없이 이어받아 틀린 화면을 본 사람이 나오면** — 경고로는 부족한 것이다. 옛 로그는 `--resume`
  을 거부하고 스코프를 요구하게 바꾼다
