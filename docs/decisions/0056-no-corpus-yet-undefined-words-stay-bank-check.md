# 0056 · 코퍼스는 지금 모으지 않는다 — 뜻 없는 낱말은 "은행 확인이 필요한 조건" 그대로 둔다

2026-09-04 · 이슈 [#71](https://github.com/hyos0415/fineprint/issues/71) · `prereg-26` ·
앞선 결정 `0011`(설명서에도 없다) · `0019`(뜻을 지어내지 않는다) · `0050`(`기타` 는 판정 불가 · 라벨 "은행 확인이 필요한 조건") ·
로드맵 §G · `CLAUDE.md` 1번(선행이 안 채워진 부품을 먼저 만들지 않는다)

## Decision

**사람이 정했다.** *"그냥 은행 안내가 필요한 항목 정도로 처리하면 안 되려나"* (2026-09-04).

```
D1  G(검색)의 코퍼스는 **지금 모으지 않는다.** 조사(`prereg-26`)가 출처를 찾았지만 — 기관 상품 상세 페이지 — 모양이
    기관마다 다르고(정적 HTML · JS 렌더 · 접속 거부 · 그룹사 페이지) 다 있지도 않다(올해의 띠). 수집 비용을 낼 근거가
    아직 사례 넷이다
D2  뜻이 공시에 없는 낱말은 **`0050` 그대로** 둔다 — 판정 불가 · 라벨 "은행 확인이 필요한 조건" · *"해당되는지는 은행에
    확인해 보세요"*. 이제 그 문장 옆에는 F3 의 홈페이지 링크·대표전화가 있다(`0051`) — 갈 곳이 생겼다
D3  도구가 못 읽은 페이지 4건(제주 탑스 · 농협 손하나로 · 부산 펫/Big · SBI 1년변동)을 **사람이 찾지 않는다.**
    도구가 못 찾은 것을 사람이 찾을 확률이 낮고, 찾아도 D1·D2 가 바뀌지 않는다
D4  조사가 찾은 뜻(소중한 날 · 페퍼 "조건 없음")을 **판정에 넣지 않는다**(`prereg-26` P5). 공시가 아닌 출처로 판정을 바꾸는
    것은 "공시를 계산한 결과" 라는 성격 고지(A13)와 부딪히고, 그 결정은 코퍼스를 모을 때 같이 한다
D5  G 의 착수 조건을 다시 적는다 — **뜻 없는 낱말 때문에 답을 못 고른 사람 세션이 쌓일 때**(지금 M1b 2건 · 표본 1명).
    그때 수집 범위(정적 HTML 만 · JS 까지 · 전부)와 판정 근거로 쓸지를 정한다. 이슈 #71 은 닫는다
```

## Evidence

`prereg-26` §6 — 낱말 4 중 공식 웹에 정의 확정 1(소중한 날 · 국민은행 상품 페이지) · 그룹사 페이지 1(탑스 · 신한 Tops Club) ·
없음 1(올해의 띠) · 미확인 1(손하나로). 조건불명 5 중 확인 2(페퍼 둘 — "조건 없는 기본 우대"). 설명서 PDF 에서 나온 것 0.

**상품설명서(A2)가 코퍼스라는 전제는 틀렸고, 상품 상세 페이지(A2')가 맞다** — 그러나 그것을 97곳에서 받는 비용이
지금의 수요(사례 넷 · 사람 1명)보다 크다. 이 판단은 `CLAUDE.md` 1번과 같은 것이다.

## Alternative

- **A. 사람이 4건을 브라우저로 확인한다** — 기각(사람). 도구가 못 찾은 것을 사람이 찾을 확률이 낮고, 결과가 D1·D2 를 안 바꾼다
- **B. 정적 HTML 만 먼저 받아 코퍼스를 시작한다** — 국민·세람·페퍼 셋으로 시작할 수 있다. 기각 — 셋으로 검색기를 만들면
  `KAG_LlamaIndex` 가 실패한 순서(구조 먼저)다. 수요가 쌓이면 D5 에서 다시 본다
- **C. 찾은 뜻을 화면에 링크로 보인다** (`0051` 방식 — "이 낱말의 설명은 기관 페이지 X 에") — 낱말 1개(소중한 날)에
  링크 하나를 손으로 박는 것이다. 사람이 관리하는 사전이 되고, 그것이 `0019` 가 막은 길의 첫 칸이다. 기각
- **D. 페퍼의 "조건 없음" 을 판정에 넣어 조건불명을 푼다** — 공시 밖 출처로 판정을 바꾸는 첫 사례가 된다. D4

## Why rejected

위에 같이 적었다.

## 반증 조건

- **사람 세션에서 뜻 없는 낱말로 답을 못 고른 사례가 쌓이면**(같은 낱말 반복 · 세션 3회 이상) — D5 발동. 코퍼스 수집 범위를 정한다
- **금융감독원 공시에 우대조건 설명 칸이 생기면** — 코퍼스가 공시 안으로 들어온다. A2' 가 필요 없어진다
- **뜻 없는 낱말 수가 늘면**(`기타` · `조건불명` 이 9월 공시에서 2배 이상) — 문장 하나로 덮기엔 많아진 것이다. D5 를 앞당긴다
- **"은행에 확인해 보세요" 를 읽고도 사람이 막힌다고 말하면** — 문장이 아니라 링크·전화가 일을 안 하는 것이다. `0051` 반증 조건과 같은 자리
