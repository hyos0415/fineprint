# 0028 · 후보 집합을 1급 개념으로 — 스코프는 사용자가 정하고, 대가를 숫자로 보여준다

2026-08-28 · 사전등록 [`../spec/prereg-11-candidate-scope.md`](../spec/prereg-11-candidate-scope.md) ·
앞선 결정 `0014`(묶는 축은 기관) · `0017`(좋은 상품을 묻지 않는다) · `0024`(P2 추정 금지 · R2 계약) ·
`0026`(질문 수 불가침) · `0027`(문구 단위 질문) ·
이슈 [#15](https://github.com/hyos0415/fineprint/issues/15)

## Decision

**0단계 축에 기관·상품군을 넣는다. 질문은 후보 집합에서만 만든다.**

```
S1  후보 집합(스코프)이 1급 개념이다 — 기관 · 상품군 · 기간 · 납입액
S2  질문은 **후보 집합에서만** 생성한다. 카탈로그 전체에서 만들지 않는다
S3  **지표는 카탈로그 전체 기준으로 고정한다** — 스코프로 지표를 좋게 만들 수 없다
S4  스코프가 걸린 화면은 **스코프 밖 최고 금리를 항상 같이 보여준다** (새 화면 계약 A7)
S5  R2 는 자연어에서 **스코프만** 뽑는다. 조건 답은 채우지 않는다 (`0024` P2 그대로)
S6  기본값은 스코프 없음(전체). 사용자가 말한 것만 스코프가 된다
```

## Evidence

### 사람이 실제 루프를 답하다가 그만두고 이유를 말했다

23개를 답한 뒤 24번째에서 중단했다(`prereg-10` §7). 그 앞 6개가 **연달아 카드실적 문구
질문**이었고, 사람이 문제를 정확히 지목했다.

> 만약 내가 우리은행 상품과 농협은행 상품에 대해서 비교를 해보기 원한다면, 제주은행
> 부산은행 상품에 대해서 전혀 관심이 없고, 질문에도 넣을 필요가 없는 거 아닌가
> (…) 질문이 많다라는 것 보다 적합한 질문을 만드는 게 더 중요하다고 느꼈어.

**로그가 그 말을 뒷받침한다.** 답한 문구 질문 8개 중 우리·농협 것은 2개였다.

```
카드실적#870c8b25   제주은행      카드실적#44a30aa9   경남은행
카드실적#e74925f3   광주은행      자동이체#1a0cce44   전북은행
```

### 스코프만으로 질문이 39개 → 7개가 된다

시나리오: *"우리은행을 주거래로 쓰는데 목돈을 모으고 싶어"*

| 스코프 | 상품 | 질문 |
|---|---|---|
| 전체 카탈로그 (지금) | 79개 | **39개** (유형 15 + 문구 24) |
| + 적금만 | 54개 | 31개 |
| + 우리은행 · 적금 | **4개** | **7개** (유형 6 + 문구 1) |

그리고 그 7개가 전부 우리은행 고객이 답할 수 있는 것이다 — `"우리은행 입출식 계좌에서
급여/연금 이체 월 수가 계약기간의 1/2이상인 경우"` 같은 문구들이고, 제주은행 카드실적이나
광주은행 펀드 보유액은 하나도 없다.

**`0014`가 이미 축을 실측해 뒀다** — 상품을 묶는 축은 기관이 가장 강했다(기관 2.17배 ·
상품군 1.25 · 권역 1.23). 그때는 "비교 쌍 뽑기" 용도로 봐서 기각했는데(남는 공유 구조가
0.3%), **후보 집합의 축으로는 그 숫자가 오히려 근거다.**

### 이것은 `0026`이 금지한 "질문 줄이기"가 아니다

```
0026 이 금지한 것   후보에 남아 있는 상품의 조건을 안 묻는다
                  → 화면에 그 상품이 있는데 근거 없는 최고 금리를 보여준다 = 과대 광고

스코프             그 상품이 화면에서 사라진다
                  → 금리를 주장하지 않으므로 과대 진술이 생기지 않는다
```

### S3 — 지표를 후보 기준으로 재면 도피가 생긴다

후보 집합을 사용자가 정하는데 지표도 후보 기준으로 재면, **쉬운 기관만 골라 확정률
95%** 를 만들 수 있다. `0018`이 막은 것과 같은 모양이다. 그래서 게이트·예산·기준선은
전부 카탈로그 전체에서 잰다. 스코프는 **사용자 화면에만** 적용된다.

### S4 — 좁히는 대가가 크다. 그래서 숫자로 보여준다

은행권 12개월, 아무것도 안 물은 상태의 최대 금리(세후)로 기관별 격차를 쟀다.

```
카카오뱅크  5.92%  격차 0.00%p     ← 전체 최고를 가진 유일한 기관
농협은행    5.12%  격차 0.80%p
부산·경남   4.06%  격차 1.86%p
우리은행    3.26%  격차 2.66%p
국민은행    3.09%  격차 2.83%p

격차 중앙값 2.41%p · 16곳 중 15곳이 1.0%p 초과
```

**2.41%p는 취향 크기가 아니다** (1천만원 1년이면 24만원). `0017`이 *"좋은 상품이
묻힌다"* 로 막은 실패를 스코프에서 되살릴 수 없다. 그래서 스코프 화면은 **밖에 무엇이
있는지**를 같이 말한다.

### 설문을 하지 않는다

사람이 물었다 — *"주거래 은행이 아니어도 우대금리가 높으면 가입할 의향이 있느냐를
조사해야 하나?"* **안 한다.** 설문으로 얻는 것은 모집단 평균이고, 그것으로 개별
사용자의 스코프를 정하면 `0024` P2(사용자 확인 없이 추정을 쓰지 않는다)를 어기는 것이다.
격차를 숫자로 보여주고 사용자가 정한다 — `0015`부터 `0027`까지 열세 번 같은 답이었다.

### "우리은행 주거래" 는 조건 답을 채우지 못한다 (S5)

실측으로 확인했다 — 그 4개 상품에 `주거래_장기거래_재예치` 조건이 **아예 없다.**
있는 것은 급여이체 · 자동이체 · 카드실적 · 마케팅 동의 · 타상품 연결 · 오픈뱅킹이고,
"주거래니까 급여이체도 하겠지" 는 추측이다. **스코프만 정하고 조건은 묻는다.**

## Alternative

| | 방법 | 왜 안 골랐나 |
|---|---|---|
| A | 지금처럼 카탈로그 전체에서 질문 생성 | 사람이 실제로 중단했다. 관심 없는 기관 때문에 답한 질문이 8개 중 6개다 |
| B | 상위 N 후보에서만 질문 생성 (스코프 없이 자동) | 답할수록 후보가 바뀌면 **질문이 다시 생겨** `0024` P4(남은 수 단조 감소)를 깬다. 별도 사전등록이 필요하다 — 지금 결정에서 제외 |
| C | 설문으로 "주거래 중시도" 를 알아내 기본 스코프를 정한다 | 모집단 평균으로 개인을 대신 정하는 것이다 (`0024` P2) |
| D | 스코프를 걸고 밖의 금리는 안 보여준다 | 2.66%p 를 숨기는 것이다. `0017`의 실패를 스코프에서 되살린다 |

## 반증 조건

- **스코프를 건 사용자가 밖의 금리를 보고도 넓히지 않으면** — S4의 경고가 소음이라는
  뜻이 아니라 **선호가 실재한다는 증거**다. 그때는 격차 표시를 유지하되 기본 스코프를
  기억하는 쪽을 볼 수 있다
- **스코프를 걸어도 질문이 20개를 넘으면** — 기관 축이 문제를 못 푼 것이다.
  우리은행은 7개였지만 상품이 많은 기관(농협 5 · 부산 7상품)은 더 많을 수 있다
- **스코프 밖 최고 금리가 거의 항상 스코프 안과 같으면** — S4가 불필요하다.
  지금 실측은 16곳 중 15곳이 1.0%p 초과라 그 반대다
- **지표를 카탈로그에서 재는 것이 실제 사용자 화면과 너무 달라지면** — 예산 12개는
  후보 4개짜리 화면에서 의미가 없다(질문이 7개뿐이다). 지표가 화면을 전혀 대표하지
  못하면 `0018`의 예산 정의를 다시 봐야 한다
- **R2가 자연어에서 스코프를 잘못 뽑으면** — 사용자가 말하지 않은 기관으로 좁히는 것은
  조건을 추측하는 것보다 더 나쁘다(상품이 화면에서 사라진다). 그래서 **뽑은 스코프는
  화면에 보여주고 사용자가 고칠 수 있어야 한다**
