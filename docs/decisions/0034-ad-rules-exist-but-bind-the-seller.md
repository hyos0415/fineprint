# 0034 · 최고금리 단독 표기 제한은 실재한다 — 다만 의무 주체는 판매업자다

> 날짜: 2026-08-31 · 상태: 유효

로드맵 I3 · 이슈 [#30](https://github.com/hyos0415/fineprint/issues/30) ·
앞선 결정 `0017`(최고 금리부터 보여주고 물어가며 깎는다) · `0026`(질문 수는 협상
대상이 아니다) · `0032`(세율은 조문 좌표에 핀) · `problem.md` §2-(가) · §8

**사전등록이 없다.** 이건 측정이 아니라 **사실 확인**이다 — 조문에 뭐라고 적혀
있는지는 읽으면 나온다(`0032` 와 같은 이유).

## Decision

**`0026` 의 반증 조건 하나를 닫는다** — *"최고금리 단독 표기 제한이 실재한다고 보지만
조문을 확인하지 않았다"*. **확인했고, 실재한다.** 반증 조건은 발동하지 않았다.

정한 것 다섯.

```
D1  `0017` 강제 1(최대값을 단독으로 쓰지 않는다 · 항상 범위)은 **조문 문구와 직접
    대응한다.** 감독규정 §17①3가 가 예금성 상품 광고에 **"이자율ㆍ수익률 각각의
    범위 및 산출기준"** 을 포함하라고 적고 있다. 근거를 문서에 박고 그대로 유지한다

D2  `0017` 강제 2(최대값 옆에 남은 조건 수)는 **조문에 그 문구가 없다.** 조문이
    금지하는 것은 결과다 — *"소비자에 따라 달라질 수 있는 거래조건을 누구에게나
    적용될 수 있는 것처럼 오인하게 만드는 행위"*(감독규정 §19①1). **개수 표시는
    그것을 막는 우리 구현**이고, 그 구분을 문서에 적는다. 근거가 약해진 것이 아니라
    **근거의 종류가 다르다**

D3  **새 요구를 하나 찾았다** — 공정위 예규가 *"수익률(이자율) 표기시 '세전'인지
    '세후'인지를 누락"* 하면 부당한 표시·광고라고 한다. **지금 CLI 는 지키고 있다**
    (헤더가 `세후 확정~최대` · `세전`). **F4(UI)에서 깨질 수 있으므로 화면 계약
    항목으로 적는다** — 다만 assert 는 아직 안 만들었다(A12 후보)
    ↑ **틀렸다. 같은 날 고쳤다** (`0035`) — `calculate.py` 목록 헤더만 보고 쓴
    말이었고, **사용자가 실제로 보는 `ask_loop` 최종 화면에는 `세후` 가 한 번도
    없었다.** 화면 맨 위에 세후 라벨을 넣고 **assert A12** 로 박았다

D4  조문 6개를 `config/ad-sources.json` 에 핀으로 박고 `fetch_law.py --check` 가
    본다. **세율 스냅샷과 파일을 분리한다** — 세율이 바뀌면 고칠 곳이
    `config/tax-2026.json` 의 **값**이지만, 광고 조문이 바뀌면 고칠 곳은
    **화면 계약**이다

D5  **우리가 이 규제의 적용 대상인지는 여기서 정하지 않는다.** (→ 같은 날 사람이
    **A·B 병기**로 화면 쪽을 정했다 · `0035`. 남은 것은 F3 가입 링크가 중개인지다)
    법 §22 의 의무 주체는
    "금융상품판매업자등" 이고 우리는 판매업자가 아니다. 그런데 같은 조 ①이
    **판매업자등이 아닌 자의 광고를 금지**한다. 이건 조문 읽기가 아니라 법률 판단이라
    사람에게 올린다 — 이슈 [#31](https://github.com/hyos0415/fineprint/issues/31)
    (`decision-needed`)
```

## Evidence

### 근거는 법 → 시행령 → 감독규정 3단으로 내려온다

법제처 국가법령정보 API 로 원문을 읽었다(2026-08-31). 좌표·해시·인용은
`config/ad-sources.json` 에 있다.

**1. 법률 — 예금성 상품 광고의 금지행위**

```
금융소비자 보호에 관한 법률 §22④3가   시행 2026-01-02 · 공포 20251001/21065

  "3. 예금성 상품
     가. 이자율의 범위ㆍ산정방법, 이자의 지급ㆍ부과 시기 및 부수적 혜택ㆍ비용을
        명확히 표시하지 아니하여 금융소비자가 오인하게 하는 행위"
```

**"범위" 라는 단어가 법률 본문에 있다.** 최고금리 하나만 쓰는 것은 범위를 표시하지
않는 것이고, 그것으로 소비자가 오인하면 금지행위다.

**2. 시행령 — 위임 두 자리**

```
시행령 §18①1라   광고에 넣을 '금융상품의 내용' = 명칭 · 이자율 · 수수료
                 + "일반금융소비자가 해당 금융상품을 이해하는데 필요하다고
                   금융위원회가 정하여 고시하는 사항"      ← 감독규정 §17 로 내려간다

시행령 §20①5     "계약 체결 여부나 금융소비자의 권리ㆍ의무에 중대한 영향을 미치는
                 사항을 사실과 다르게 알리거나 분명하지 않게 표현하는 행위" 금지
        §20①6     + 고시 위임                              ← 감독규정 §19 로 내려간다
```

**3. 감독규정 — 여기서 예금성 상품이 이름으로 나온다**

```
금융소비자 보호에 관한 감독규정 §17①3   (금융위원회 고시 2026-11 · 시행 2026-04-02)

  "3. 예금성 상품
     가. 이자율ㆍ수익률 각각의 범위 및 산출기준
     나. 이자ㆍ수익의 지급시기 및 지급제한 사유"
```

이것이 **광고에 포함해야 하는 사항**이다. `0017` 강제 1 과 문구가 그대로 겹친다 —
우리가 `2.54 ~ 5.92%` 로 쓰는 것이 "범위" 이고, 조건별 우대 분해가 "산출기준" 이다.

```
감독규정 §19①1 (그리고 §19③1 — 같은 문구가 두 번 나온다)

  "금융소비자에 따라 달라질 수 있는 거래조건을 누구에게나 적용될 수 있는 것처럼
   오인하게 만드는 행위"
```

**우대금리는 정확히 "소비자에 따라 달라질 수 있는 거래조건" 이다.** 최고금리를 누구나
받는 것처럼 보이게 하는 것이 금지행위다.

### 다만 "최대값을 쓰면 최소값을 함께" 라고 **명시한 조문은 투자성 상품 전용이다**

```
감독규정 [별표 5] 광고에 포함해야 하는 사항 · 3.가.5)

  "최소비용을 표기하는 경우 그 최대비용과 최대수익을 표기하는 경우 그 최소수익"
                                                    ← 투자성 상품에만 걸린다
```

별표 5 에 **예금성 상품 항목이 아예 없다.** 예금성은 위의 §17①3 가 "범위·산출기준"
으로 규율한다. 그래서 정직하게 갈라 적는다.

```
0017 강제 1 (범위로 쓴다)        조문 문구와 직접 대응     감독규정 §17①3가
0017 강제 2 (남은 조건 수)       조문이 금지하는 결과를    감독규정 §19①1 · 영 §20①5
                              막는 **우리 구현**        (개수를 쓰라는 문구는 없다)
```

**D2 가 이 확인의 실제 수확이다.** 강제 2 를 "법이 그렇게 하라고 했다" 고 쓰려던
자리에서, 법은 *"오인하게 만들지 말라"* 까지만 말한다는 것을 알았다.

### 예상 밖의 것 — 세전·세후를 안 밝히면 부당한 표시·광고다

법 §22⑤ 가 *"「표시ㆍ광고의 공정화에 관한 법률」 제4조제1항에 따른 표시·광고사항이
있는 경우에는 같은 법에서 정하는 바에 따른다"* 로 표시광고법을 함께 걸어 둔다.
그 법 아래 공정위 예규가 있다.

```
금융상품 등의 표시·광고에 관한 심사지침 (공정거래위원회 예규 273 · 2016-12-23) Ⅴ.1.마

  "수익률(이자율) 표기시 '세전'인지 '세후'인지를 누락하여 표시·광고하는 것은
   부당한 표시·광고에 해당할 수 있다."
```

**우리는 이미 지키고 있다** — `calculate.py` 의 목록 헤더가
`세후 확정~최대` · `세전` 이고 두 칸을 나란히 낸다. 찾아서 확인한 것이지 고친 것은
아니다. 문제는 **그 라벨을 지키는 장치가 없다는 것**이다 — 화면 계약 assert A1~A11 에
세전/세후 라벨 항목이 없고, F4(UI)로 옮기면 조용히 사라질 수 있는 종류다.

> **정정 (같은 날 · `0035`).** 위 문단이 틀렸다. **`calculate.py` 목록만 보고 썼다** —
> 사용자가 실제로 보고 화면 계약 검사가 읽는 `ask_loop` 최종 화면에는 `세후` 라는 말이
> **한 번도 없었다**(grep 0건). "지키고 있다" 가 아니라 **한쪽 화면에서 누락**이었다.
> 세후 라벨을 화면 맨 위에 넣고 **assert A12** 로 박았다. F4 위험을 걱정하기 전에
> 이미 새고 있었던 것이다.

같은 예규에 우리 층 라벨과 겹치는 것이 하나 더 있다 — Ⅴ.1.가 *"상품광고시점에 있어
유사한 종류의 타 상품에 비해 상대적으로 높은 이자율을 제공할 수 없음에도 제공하는
것처럼"*. `0019` 의 부산은행 사례(조건이 한 글자도 없는데 4.80% 로 보였다)가 그 모양이다.

### 오늘 만든 코드가 그대로 안 붙었다 — `admrul` 은 응답 구조가 다르다

```
법령 (target=law)                    행정규칙 (target=admrul)
법령ID          ← 핀 →               행정규칙ID
법령일련번호(MST) ← 매번 새로 →        행정규칙일련번호
공포일자/공포번호  ← 대응 →            발령일자/발령번호
현행연혁코드                          현행연혁구분
조문단위[]  = dict 리스트             조문내용[] = **문자열 리스트**
  (조문번호·조문가지번호·조문여부·        ("제17조(광고의 내용) ① …" 처럼 좌표가
   조문시행일자 필드가 따로 있다)          본문 앞머리에 붙어 있을 뿐이다)
본문 조회 파라미터 = MST              본문 조회 파라미터 = **ID**
                                     그리고 그 ID 는 행정규칙ID(77048)가 아니라
                                     **행정규칙일련번호**(2100000276850) 다
```

**같은 `target` 안에서도 형태가 갈린다.** 공정위 예규는 `조문내용` 이 **문자열 하나**로
온다(장·절이 로마숫자라 조문 단위가 아니다). 그래서 그 행만 `조: None` 으로 두고
전문을 해시한다.

**법령 쪽 함정(`조문여부='전문'` 인 편·장 헤더가 같은 조문번호로 섞인다 · `0032`)에
대응하는 것을 찾아봤는데 감독규정에는 없었다** — 조문내용 36개 원소가 전부 `제N조` 로
시작하고 좌표 중복이 0이었다. 다만 기본정보에 `조문형식여부` 필드가 있으니 조문
형식이 아닌 행정규칙도 있다. 조문을 못 찾으면 죽는 쪽으로 뒀다.

### 동작을 확인했다

```
python src/ingest/fetch_law.py --snapshot ad
  조문 6개 · **볼 문구 6개 전부 매치** (홑따옴표가 유니코드 ‘ ’ 인 예규까지)

python src/ingest/fetch_law.py --check
  세율      규범 3개 · 조문 5개 · 바뀐 조문 0개      ← 기존 경로 그대로 (하위 호환)
  광고 규제  규범 4개 · 조문 6개 · 바뀐 조문 0개
  종료코드 0

스냅샷의 발령번호·해시를 개정된 것처럼 바꿔 놓고 다시 돌렸다
  감독규정      1단에서 "바뀌었다" → 2단으로 본문을 긁어 조문 2개 대조 → **조문은 그대로**
  공정위 예규    2단에서 해시 불일치 → "조문이 바뀌었다" + 고칠 곳(화면 계약)을 지목
  종료코드 1
```

1단 비용은 규범 하나당 2.5KB 다. 광고 규제가 규범 4개를 더하므로 `--check` 의 1단이
3개 → **7개**로 늘고, 총 약 17KB 다. 월 1회다.

## Alternative

- **A. 조문을 읽고 문서에만 인용을 적는다** — 스냅샷·감시를 안 만든다
- **B. 세율 스냅샷(`config/tax-sources.json`)에 광고 조문을 같이 넣는다** — 파일 하나
- **C. 감독규정만 감시한다** — 예금성 문구가 거기 있으므로 법·시행령은 뺀다
- **D. 광고 규제를 감시하지 않는다** — 화면 계약은 우리가 정한 것이니 조문과 무관하게 둔다
- **E. `0017` 강제 2 를 "법적 근거" 라고 적는다** — §19①1 이 그 취지이므로
- **F. 우리가 규제 적용 대상인지까지 여기서 정한다**

## Why rejected

- **A** — `0032` 가 기각한 대안 D 와 같은 모양이다. **광고 규제는 세법보다 더 자주
  움직인다** — 감독규정이 2026-04-02 시행, 시행령이 2026-04-28 시행으로 올해 둘 다
  개정됐다. 한 번 읽고 끝내면 내년에 오늘과 똑같은 상태가 된다
- **B** — 파일은 하나가 되지만 **"바뀌면 무엇을 고치나" 가 섞인다.** 세율은 config 의
  값이고 광고는 화면 계약이다. 섞으면 `--check` 가 알림을 내도 사람이 어디를 봐야
  하는지 알 수 없다. 코드는 이미 공유한다(스냅샷 묶음이 둘일 뿐이다)
- **C** — 감독규정은 고시라 **위임 근거가 사라지면 함께 무력해진다.** 실제로 §17①3 은
  영 §18①1라목의 위임이고 §19①은 영 §20①6의 위임이다. 위임 조문이 개정되면 고시
  문구가 그대로여도 의미가 달라질 수 있다. 3단을 다 본다
- **D** — `0026` 이 자기 반증 조건에 *"금융 규제가 반대 방향이면 이 결정의 근거 하나가
  사라진다"* 를 적어 뒀다. 그 조건을 감시하지 않으면 반증 조건이 장식이 된다
- **E** — 없는 근거를 만드는 것이다(`CLAUDE.md` — *"없는 근거를 만들지 않는다"*).
  조문은 "오인하게 만들지 말라" 까지만 말한다. 개수 표시가 그 목적에 맞는 수단이라는
  것은 **우리 판단**이고, 그렇게 적어야 나중에 더 나은 수단이 나왔을 때 바꿀 수 있다
- **F** — `CLAUDE.md` 2번이 막는다(**열린 결정을 임의로 확정하지 않는다**). 판례·
  유권해석이 필요한 판단이고 조문만으로 안 갈린다. 후보와 trade-off 를 이슈 #31 에
  정리해 사람에게 올렸다

## 반증 조건

- **`--check` 가 광고 조문 개정을 잡았는데 화면 계약을 안 고치면** — 알림만 있고 강제가
  없는 것이다. `0032` 가 세율에 대해 적은 것과 같은 자리이고, 그때는 월간 파이프라인이
  **계산 전에 멈추게** 한다
- **감독규정 §17①3 이나 §19①1 의 문구가 바뀌어 "범위" 요구가 사라지면** — `0017`
  강제 1 의 법적 근거가 없어진다. **그래도 유지한다** — `0026` D4(편의와 정직 사이에서
  타협하지 않는다)는 사람이 정한 방향이라 규제와 독립이다. 다만 문서에서 "법이 요구한다"
  를 지우고 "우리가 정한다" 로 고쳐야 한다
- ~~**F4(UI)에서 세전·세후 라벨이 사라지면**~~ — **같은 날 발동했고, 대응까지 했다**
  (`0035`). F4 를 기다릴 필요도 없었다 — 질문 루프 화면에 이미 없었다. `A12` 를
  `check_screen_contract.py` 에 넣었고 은행권·저축은행 전수에서 통과한다
- **이슈 #31 의 답이 "우리는 광고에 해당한다" 로 나오면** — 법 §22① 이 판매업자가 아닌
  자의 광고를 금지하므로 **서비스 형태 자체를 다시 봐야 한다.** 그때는 이 결정이 아니라
  `problem.md` §8(안 하는 것)이 바뀐다
- **`조문형식여부: N` 인 행정규칙을 감시 대상에 넣어야 하면** — 지금 `admrul_article`
  은 조문 형식과 전문(문자열 하나) 둘만 다룬다. 세 번째 형태가 나오면 죽는다.
  죽는 쪽으로 둔 것이 맞는지 그때 다시 본다
