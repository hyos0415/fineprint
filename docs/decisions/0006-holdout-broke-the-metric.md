# 0006 — 홀드아웃이 지표의 전제를 깨뜨렸다. 사전등록 판정을 채택하지 않는다

> 날짜: 2026-08-25 · 상태: 유효 · 이슈 #5 · 사전등록 `../spec/prereg-03-extraction.md`

## Decision

세 가지를 정한다.

1. **`prereg-03`의 사전등록 판정("제한 스키마 채택")을 채택하지 않는다.** §8 두 번째
   반증 조건이 발동했다 — A·B 모두 닫힘률 40% 미만이고, 원인이 지표의 전제 붕괴로
   확정됐다. 반증 조건은 측정 전에 적어둔 것이므로 판정보다 앞선다
2. **저축은행은 이 지표의 홀드아웃으로 쓰지 않는다.** 분모 1,090행 중 908행(83.3%)이
   어떤 추출로도 닫힐 수 없는 행이다
3. **A 규칙 파서의 성능은 10.5%가 아니라 62.6%로 기록한다.** 지표가 성립하는 행에서
   개발 집합(62.8%)과 사실상 같다. 과적합되지 않았다

## Evidence

**전제 붕괴 (확정).** 닫힘률은 "항목 합계가 (최고금리 − 기본금리)와 0.06%p 이내로
맞는가"다. 홀드아웃에서 **조건문이 있는 1,090행 중 908행(83.3%)이 최고금리 =
기본금리**다. 차이가 0이면 맞출 방법이 없다 — 뽑으면 넘치고, 안 뽑으면 항목 0개다.

원본 필드로 확인했다. 코드 버그가 아니다.

```
KB저축은행 · 정기예금 · 3개월
  intr_rate = 2.0   intr_rate2 = 2.0
  spcl_cnd  = "… 당일 창구 신규시 우대금리 연 0.1%p 적용 …"
```

**저축은행은 우대금리를 최고금리 필드에 반영하지 않는다.** 은행권은 반영한다(조건 있는
상품 81건 전부 폭 > 0). 같은 API·같은 필드인데 기관군의 기입 관행이 다르다.
`prereg-03` §2가 "같은 공시 체계"라고 본 전제가 이 지점에서 틀렸다.

**측정값.** 사전등록 지표 전부 (§7 표)

| | A 규칙 파서 | B 제한 스키마 |
|---|---:|---:|
| 닫힘률 (행 1,090) | 10.5% | 13.6% |
| 가중 닫힘률 (조건문 75종) | 31.0% | 40.6% |
| 항목 0개 비율 | 21.4% | 19.6% |
| 스키마 위반 | — | 0/228 |
| 비용 | ~0 | $1.00 · 487초 |

McNemar p < 0.0001 · Wilcoxon p = 0.0001 · 가중 닫힘률 차이 CI [+0.2, +18.9]%p.

**사전등록대로면 판정은 "채택"이었다.** 주 지표와 가중 닫힘률이 갈렸고(`0005`의 규칙에
따라 가중이 지배), +9.6%p ≥ 5%p, p < 0.05, §4 제약도 통과했다(B의 항목 0개 비율이
1.7%p 더 **낮다**). **그런데 그 +9.6%p가 대부분 폭 = 0 행에서 나온다** — 그 부분집합에서
A 0.0% / B 8.1%다. 닫을 수 없는 행에서 "이긴다"는 말은 의미를 갖지 않는다.

**A의 실제 성능 (사후 분석 · 라벨 붙임).** 폭 > 0인 182행에서 A 62.6% · B 71.4%
(+8.8%p, p = 0.0987, CI [−9.8, +27.6]). A의 62.6%는 개발 집합 62.8%와 사실상 같다.

## Alternative

- **(가) 사전등록 판정을 그대로 채택한다** — "제한 스키마 채택"
- **(나) 사후에 분모를 고쳐(폭 > 0) 그 결과를 판정으로 쓴다** — +8.8%p
- **(다) 저축은행 홀드아웃을 폐기하고 개발 집합에서 비교한다**
- **(라) 허용 오차 0.06%p를 넓혀 다시 잰다** — 불일치 폭 분포에서 A 649행·B 652행이
  0.06~0.30 구간에 있다

## Why rejected

- **(가) 판정 그대로 채택**: 반증 조건을 측정 전에 적어둔 이유가 이것이다. 근거 숫자가
  "닫을 수 없는 행"에서 나온 것을 알고도 채택하면, 사전등록이 결론을 정당화하는 장식이
  된다. 선행 저장소가 반복한 실패의 모양이다
- **(나) 사후 분모 수정을 판정으로**: 결과를 본 뒤 분모를 고르는 것이다. `CLAUDE.md`
  3번이 금지하는 바로 그것이며, 이 프로젝트의 규율 전체를 무효화한다. **다음 사전등록에서
  분모를 고쳐 다시 재는 것**이 옳은 순서다 (`prereg-04`)
- **(다) 개발 집합에서 비교**: A는 그 253행을 여덟 라운드 보면서 만들어졌다. 과적합된
  baseline과 겨루는 것이고 `prereg-03` §2가 처음부터 배제한 방향이다
- **(라) 허용 오차 확대**: 임계를 결과 본 뒤에 넓히는 것이다. 0.06%p는 `prereg-02`에서
  정해 파일럿까지 쓴 값이고, 지금 넓히면 "닫힘"의 정의가 실험마다 달라진다. 0.06~0.30
  구간에 몰린 것은 **관측으로 기록**하고 다음 사전등록에서 근거와 함께 다룬다

## 채택하지 않았지만 확정된 것

판정과 별개로, 사전등록한 부 지표에서 확정된 것이 있다.

- **제한 스키마는 형식으로서 작동한다** — 스키마 위반 **0/228** · `기타` **4.7%**(16/340
  항목) · 항목 0개 비율이 A보다 **낮다**. 개발 집합만 보고 만든 열거값 16종이 처음 보는
  기관군 79곳의 문장을 4.7%만 흘렸다. "형식을 제한하면 뽑기를 포기한다"는 우려(§4)는
  관측되지 않았다
- **비용은 판단 요소가 아니다** — 228호출 $1.00 · 8분. §4가 걱정한 "3%p 우위에 100배
  비용"이 아니다

## 반증 조건

- **폭 > 0으로 분모를 고친 뒤에도 A·B 차이가 ±5%p 안이면** → "추출 시점 형식 제한이
  답이다"가 틀린 것이다. `0004`의 첫 번째 반증 조건이 발동한다
- **다른 권역에서도 최고금리 = 기본금리인 행이 과반이면** → 문제는 저축은행이 아니라
  **지표**다. 닫힘률을 버리고 다른 채점 방식을 찾아야 한다
- **은행권을 다시 수집했을 때 폭 = 0 행이 나타나면** → 기관군 차이가 아니라 시점 차이일
  수 있다. 그러면 이 결정의 (다)("기입 관행이 다르다")가 틀린 것이다
- **폭 > 0 표본을 182 → 500행 이상으로 늘렸을 때 A가 62% 근처를 유지하지 못하면** →
  "A는 과적합되지 않았다"가 182행의 우연이었다는 뜻이다
