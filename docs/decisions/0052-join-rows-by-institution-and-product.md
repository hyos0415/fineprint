# 0052 · 행은 기관코드+상품코드로 붙인다 — 저축은행 값은 전부 새 기준선이다

2026-09-04 · 이슈 [#61](https://github.com/hyos0415/fineprint/issues/61) `blocking` · `prereg-22` ·
잡은 곳 `0051`(F3 의 A17) · 앞선 결정 `0031`(상품은 기관코드+상품코드로 센다)

## Decision

```
D1  `extract_llm.load_pairs()` 는 옵션 행을 상품에 **(fin_co_no, fin_prdt_cd)** 로 붙인다. 상품코드만으로
    붙이지 않는다 — 코드는 기관을 넘어 유일하지 않다 (`0031` 이 적어 둔 사실)
D2  옛 추출 결과는 **(문구, 기간)** 으로 재사용한다 (`--reuse`). 같은 입력 · temperature 0 · 같은 호출이고
    "같은 쌍은 재사용한다" 는 원래 설계다. 새 쌍만 부른다. `pair_id` 는 새로 매긴 완전한 파일로 낸다
D3  **저축은행으로 잰 옛 값은 비교 대상이 아니라 교체 대상이다.** `prereg-22` §6 의 표가 새 기준선이다.
    옛 값이 적힌 기록은 고치지 않고 머리에 "#61 이전" 을 단다. 은행권 값은 그대로 유효하다
D4  게이트 기준선(`0018` 저축은행 36.7%)은 **사람이 다시 정한다** — 옛 값이 결함의 산물이라 그대로 둘 수
    없고, 새 값(64.3%)을 기준선으로 삼을지는 측정이 아니라 결정이다. 이슈 #10 에 적었다
```

## Evidence

`prereg-22` §6 — 여섯 예측 전부 적중. 고친 것은 키 한 줄이다.

```
저축은행 행       1,090 → 583 (12개월 297 → 196)   틀린 짝으로 남의 조건이 붙었던 행이 실제로는 "조건없음" 상품
쌍               228 → 284 · 재사용 199 · 새 호출 85 (85/85 통과 · $0.41)
코드 ≠ 이름 행    160 → 0
게이트           106/297 = 35.7% → 126/196 = 64.3%
질문 총수         61 → 71 · 화면 상품 71 → 92
화면 계약         A1~A17 전부 통과 (hi·lo)
은행권           행·쌍 순서 동일 — 영향 0
```

**왜 이제야 나왔나.** 이름·조건이 남의 것이어도 금리와 코드는 진짜였고, 화면은 이름과 금리만 보였다.
검사기는 이름과 코드가 같은 기관인지 물은 적이 없었다. F3 가 코드로 링크를 붙이고 A17 이 *"링크가 가는
기관 = 이름의 기관"* 을 물은 순간 걸렸다. `0031`(A11 이 상품 수 오류를 찾음)과 같은 모양이다 — **계약을
하나 더하면 옛 결함이 나온다.**

## Alternative

- **A. 옛 파일의 `pair_id` 를 유지하고 새 쌍만 뒤에 붙인다** — 옛 파일의 순서는 틀린 행 순서다. 소비자 8곳이
  자리 번호로 읽으므로 두 순서를 섞으면 어느 행이 어느 쌍인지 보증할 수 없다. 완전한 새 파일이 맞다
- **B. 284쌍을 전부 다시 부른다** — $1.4 · 같은 입력에 같은 답이라 얻는 것이 없고 재현성 기록만 흐려진다
- **C. 게이트 기준선을 64.3% 로 여기서 확정한다** — 기준선은 `0018` 에서 사람이 정한 값이고 #10 이 열려 있다.
  측정이 결정을 대신하지 않는다
- **D. 옛 문서의 저축은행 숫자를 새 값으로 고쳐 쓴다** — 기록을 지우는 것이다. 표시를 달고 두는 쪽이 맞다

## Why rejected

위에 같이 적었다.

## 반증 조건

- **원천 `optionList` 에 `fin_co_no` 가 없는 행이 생기면** — D1 의 키가 못 붙는다. 그 행은 빼고 수를 적는다
- **같은 (문구, 기간)에 옛 결과와 새 호출이 다른 답을 내면** — D2 의 전제(temperature 0 재현성)가 깨진 것이다.
  `prereg-03` §6 의 실행 조건을 다시 본다
- **9월 공시에서 은행권에도 코드 겹침이 생기면** — 은행권 값도 이 결정의 영향권에 들어온다. `--check` 처럼
  겹침 수를 세는 자리를 만든다
- **#10 에서 사람이 옛 기준선을 유지하기로 하면** — D4 가 열어 둔 선택이다. 그 사유를 #10 과 `0018` 에 적는다
